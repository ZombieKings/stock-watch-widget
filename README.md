# Stock Watch Widget

A股行情 + 当日新闻桌面悬浮小窗。基于 Electron 的 Windows 桌面挂件，提供实时行情、走势图、资讯、持仓盈亏、交易流水与价格预警，支持完整 / 列表 / 单行三种窗口模式。

## 功能特性

- **关注列表**：支持按股票代码、名称或拼音搜索，股票和场内基金均可添加；可拖拽排序、设置别名和成本/持仓。
- **实时行情**：价格、涨跌幅、开高低收、成交量/额、换手、量比、PE/PB、市值等；基金额外展示溢价率与估算净值。
- **走势图**：分时、5日分时、60分钟K、日K、周K；日/周K展示 MA5/10/20，支持滚轮缩放、拖拽平移和悬停读数。
- **可折叠分组**：技术指标（MACD / RSI / KDJ / BOLL）、资金流向、融资融券、财务指标、龙虎榜、研报和本地交易记录。
- **资讯时间线**：个股新闻、公司公告、研报按时间倒序合并展示，可筛选“全部 / 新闻 / 研报”，并切换只看当日。
- **持仓与交易**：可手工填写成本/数量，也可记录买卖流水；持仓按流水优先推导，展示浮动盈亏和已实现盈亏。
- **价格预警**：支持涨跌幅、价格、持仓盈亏三类条件，触发 Windows 系统通知，每条规则每天最多提醒一次。
- **三种窗口模式**：完整详情、多股列表、单行条，自动记住上次窗口位置、尺寸和模式。
- **托盘驻留**：隐藏后从系统托盘唤回；单实例运行，二次启动会唤起已有窗口。

## 快速开始

```powershell
npm install
npm start
```

首次启动后，点击标题栏右侧的 ⚙ 打开设置：

1. 在“添加股票 / 基金”中输入代码、名称或拼音，例如 `600519`、`茅台`、`510300`、`黄金ETF`。
2. 添加后可拖动排序，也可填写别名、成本价和持仓数量。
3. 点击“保存”，主界面会自动开始拉取行情。

## 常用操作

| 操作 | 方式 |
| --- | --- |
| 切换窗口模式 | 双击标题栏、`Ctrl+M`、右键菜单或托盘菜单 |
| 刷新行情 | `F5`、`Ctrl+R`，或点击 ↻ |
| 切换股票 | ◀ / ▶，或在股票名称上滚动滚轮 |
| 关闭设置 / 下拉 | `Esc` |
| 打开设置 | 标题栏 ⚙，或托盘右键菜单 |
| 退出 | 标题栏 ✕，或托盘右键菜单“退出” |

## 开发命令

```powershell
# 启动开发运行
npm start

# 运行测试（Node 内置 test runner）
npm test

# 生成 build/icon.ico 与 assets/tray-*.png（可选）
npm run icon

# 打包 Windows 应用（生成 NSIS 安装器与 portable 版）
npm run dist

# 只生成便携版
npm run dist:portable
```

打包产物默认输出到 `release/`。

## 数据来源

本项目直接请求公开行情/资讯接口，无需 API Key：

| 数据 | 来源 |
| --- | --- |
| 实时行情、当日/多日分时、日/周K | 腾讯行情 |
| 60分钟K | 东方财富 |
| 个股新闻 | 新浪财经，东方财富搜索作备用 |
| 公司公告、资金流向、融资融券、财务指标、龙虎榜、研报 | 东方财富 |
| 交易日历 | 深圳证券交易所 |

## 本地数据

配置与交易记录保存在 Electron `userData` 目录，Windows 下通常为：

```text
%APPDATA%\StockWatchWidget\
├── config.json          # 关注列表、预警规则、窗口位置等
├── trades.json          # 交易流水
└── alerts-state.json    # 预警去重状态
```

## 项目结构

```text
├── main.js                  # Electron 主进程：窗口、托盘、IPC、预警
├── preload.js               # contextBridge 安全桥接
├── src/                     # 服务与逻辑层（客户端、指标、配置、存储）
├── renderer/                # 渲染层（HTML/CSS/JS，Canvas 图表）
├── assets/                  # 运行时托盘图标
├── build/                   # 打包图标与图标生成脚本
└── package.json
```

## 说明与注意事项

- 行情轮询会按交易时段自动调整：盘中约 3 秒，收盘后/周末约 5 分钟；新闻固定约 3 分钟刷新。
- 窗口为透明无边框、置顶显示，任务栏不显示入口，隐藏后请从系统托盘唤回。
- 第三方接口可能改版或限流，如某类数据不可用，相关分组会显示错误/空态，不影响其他数据。
- 本项目仅用于行情查看与记录，不构成投资建议。
